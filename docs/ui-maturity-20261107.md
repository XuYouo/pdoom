# 前端交互完善 · 2026-11-07

延续 [11 月 6 日的主菜单与 HUD 打磨](ui-polish-20261106.md)，依据 `GAME_DESIGN_GDD.md` 的暗色终端、暖橘与像素世界风格，完善训练前后和异常情况下的完整操作路径。

## 界面与行为

- 暂停、失败和章节突破共用真实状态摘要：章节、HP、Doom、累计时间、算力、得分与五章进度。失败结果和可恢复的安全检查点分别呈现；Leviathan 吞掉的当前 HP 不会在暂停页重新出现。
- 主菜单、失败页和结局页的新训练入口统一保护已有本地进度。确认框展示即将替换的记录，默认聚焦“保留当前进度”；取消不改档，确认后才开始训练。完成档明确说明将失去本地结局回看入口。
- 设置页重排为声音、动态效果和补充说明。主音量显示实际百分比，静音保留音量，减少动态效果可用键盘选择。桌面、竖屏和短横屏的关闭入口保持可达；关闭设置不会恢复战斗。
- 账户页采用键盘可切换的登录/注册标签、本地与云端检查点对照，以及游戏内的载入确认。读取、上传、载入仍然需要玩家明确操作。云端载入提示准确说明会退出当前战斗、返回终端。
- 成绩页说明登录、提交中、成功和失败重试状态，避免向玩家展示运行标识等实现术语。保留非竞技说明、显式提交、不可更换原始成绩和幂等重试。
- 加载页显示 Phaser 的真实资源进度；加载或失败时使用原生模态阻止背景交互，失败默认聚焦重试，并保留本地检查点。
- 训练记录的空页或请求失败仍可返回上一页，不再被困在分页错误状态。表格提供独立横向滚动。
- 嵌套确认框的 Escape 只关闭最上层，避免同时关闭账户面板或跳过结局演出。暂停页说明返回终端只保留最近检查点；恢复写入失败在操作旁直接显示。
- 成功结局的完成记录若写入失败，演出和结算都持续显示未保存警告，说明刷新或离开可能失去本页结果。正常保存时的结局流程保持原样，成绩仍须手动上传。

## 实现边界

遵循 `架构与开发规范参考.md`：页面组件与纯展示派生函数就近组织，React 只处理界面状态和低频快照，Phaser 继续拥有战斗模拟。新增的加载进度由独立 `BootOverlay` 订阅，未增加逐帧 React 更新。

没有修改 Scala API、存档 schema、战斗数值、物理或资产内容；角色展示仍使用现有 Aseprite 导出图集。已有工作区修改保留。旧浏览器用例仅适配明确新增的确认步骤、语义标签与当前指南内容，不降低原有战斗断言或等待预算。
