# 第一章核心循环与上下文休息室验证

可玩范围仍为第一章，没有五关通关入口、调试作弊键或运行时测试后门。Phaser 4.0.0 负责输入、镜头与显示；固定 60 Hz 的纯 TypeScript 世界模型负责运动、扫掠碰撞、战斗与回溯。第二轮增加上下文与商店，完整编码和效果说明见[第二轮设计记录](../../docs/round2-context.md)。美术资源由 lead 独立整合，本说明不冒称最终美术已验收。

## React 集成契约

`createGame(parent: HTMLElement, bridge: GameBridge): Phaser.Game` 从 `src/pages/GamePage/game/config.ts` 导出。

1. React 先注册事件，再创建游戏；卸载时 `game.destroy(true)`，自己释放 bridge。
2. `ready` 时世界静止，不计时、不移动敌人、不发射敌弹；收到 `start/restart` 才开始运行。
3. `hud` 游戏中不高于 5Hz（开始、暂停和结束等离散状态变化会立刻发送）。
4. 正式检查点、休息室交易/排序/离开与章节完成发 `checkpoint`。暂停不保存中段拾取奖励，避免 DTO 无拾取 ID 时重新进入段首重复收集。休息室内交易与编码在同一个完整DTO中保存。
5. Gato 死亡：`checkpoint`（save.stage=2, checkpoint=0）→ `stage-cleared`（stage=1）→ 明确第一章通过的 `notice`。不会发最终 `ending`。
6. 生命耗尽或坠落只发 `ended`，`ending='defeat'`。结算对象不应覆盖此前可继续的存档。
7. `start` 收到第 2–5 章存档时，保留 DTO、显示未开放提示、不进入模拟，也不覆盖为第一章。
8. 战斗中的Esc、窗口blur、页面hidden会暂停并发 `pause-requested`，只有 `resume` 才恢复。后台不会消耗免疫时间。休息室则由独立rest状态冻结，只有 `rest-continue` 可离开，普通resume不能绕过。

## 手工试玩路径

- A/D 或左右方向移动；Space/上方向跳跃；按住 Space 高跳、松开短跳。
- J 持续水平射击；鼠标按住可瞄准射击。Shift 冲刺，Q 回溯，E 透视，Esc 暂停。
- 首个断层位于 x=640；常规路线每个 100px 断层都有上方跳台。较高支路的紫色算力可绕开，不强迫增加 Doom。
- 在复读机前行动至少 2 秒后按 Q，确认沿轨迹移动、穿到的弹幕消失，HUD notice 报类型免疫及暴击；其他弹种仍会伤害，已获得类型 10 秒后恢复伤害。
- 在森林用 E，伪装者头顶出现小红核心；鼠标精准击中即杀，不是随便打身体就秒杀。
- 检查点在 x=1380、2180，地面有旗标与生命拾取。进入后验证计时冻结、商店可跳过；购买或劫持后刷新恢复，应保留余额、装备、捐赠和劫持标记，不重复评级。旧1/2检查点直接继续，不追发商店奖励。
- 收集三枚以上禁忌算力进入 >80% FOOM：输出/弹速/承伤提高，裂纹跳台接触后先预警 750ms 再坍塌。蘑菇反转重力 1.7s，有安全顶部边界。
- x=2240 激活 Gato 并封闭竞技场。第一阶段左侧金色挡板预警时反射前方来弹，可绕后或等恢复窗口；第二阶段地面红框锁定砸击，跳过冲击波；第三阶段七发字幕扇形弹。
- 清关面板必须说“第一章通过 / 第二章入口已保存”，不出现 aligned/warden/foom 最终结局。
- 在运行、暂停和 ready 状态反复卸载/挂载，确认无双 canvas、无残留键盘响应和 bridge 监听器。
